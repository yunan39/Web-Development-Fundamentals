How to use this tracker

Follow these steps to use your Budget Tracker:

  1. Enter the name of your expense.
  2. Enter the amount spent in KSh.
  3. Select a category from the dropdown menu.
  4. Choose the date of the expense.
  5. Click the Add Expense button.

Note: The Add Expense button is not functional yet. Automatic expense recording will be added later using JavaScript.
